# 🎮 AlAWNEH GAMING

## 🏪 Overview

The Alawneh Gaming online store is a website that you can shop for anything related to video games. It includes games, gaming chairs, desks, and even gaming accessories.


## 🗝️ Features

- **Login:** Able to login to the website as a admin or a user.
- **Price and Category filtering:** Able to search for products using price and category filterings.
- **Cart function:** Able to add items you want into a cart where you can view and clear your cart If you don't want the items anymore.
